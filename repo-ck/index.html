РЕПО с ЦК для юридических лиц

с 20 июля 2026 — новый инструмент для краткосрочного размещения рублёвой ликвидности

Доступ

Автоматически предоставляется всем юридическим лицам в QUIK

Инструменты

Однодневные сделки РЕПО с акциями, облигациями и клиринговыми сертификатами участия (КСУ)

Доступно только размещение денежных средств — заём ликвидности через РЕПО с ЦК не предусмотрен
Источник: внутренняя рассылка АТОН, по состоянию на 08.07.2026

Условия размещения и тарифы

Торговый режим

Торговать можно до 17:00
После 17:00 свободные рублёвые остатки размещаются казначейством автоматически по ставке RUSFAR − 0,8% (вместо стандартной RUSFAR − 0,5%)
