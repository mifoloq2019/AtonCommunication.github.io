## Как обновить

1. Добавьте или замените папку `имя-страницы/index.html`
2. Обновите ссылку в корневом `index.html`
3. Закоммитьте и запушьте в `main`

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root
