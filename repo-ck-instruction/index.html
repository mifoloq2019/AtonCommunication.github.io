QUIK · Размещение ликвидности

Пошаговая инструкция
по размещению в РЕПО с ЦК

7 шагов в торговом терминале TC QUIK

9 июля 2026
Шаг 1 из 7
1

Выберите режим торгов

Размещение свободных денежных средств доступно в TC QUIK. Выберите один из трёх режимов:

EQRP — РЕПО с ЦК 1 день (Акции)
EQRP_BND — РЕПО с ЦК 1 день (Облигации)
GCRP — РЕПО с ЦК 1 день (КСУ)
Важно: Минимальная заявка — от 100 000 руб. Время выставления — до 17:00
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 2 из 7
2

Найдите режим в QUIK

В рабочем месте QUIK в поле «Поиск инструмента» введите название нужного режима торгов и нажмите Enter.

Важно: Например: EQRP, EQRP_BND или GCRP
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 3 из 7
3

Откройте стакан

Выберите нужный инструмент, через который хотите совершить размещение. Откройте стакан одним из способов:

Двойное нажатие левой кнопкой мыши по инструменту
Правая кнопка мыши → «Стакан»
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 4 из 7
4

Изучите ставки в стакане

В открывшемся стакане отображаются заявки на покупку и продажу. Цена означает годовую % ставку, по которой будет происходить размещение.

Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 5 из 7
5

Создайте заявку

Двойным нажатием по стакану или через ПКМ → «Новая заявка» откройте окно для заполнения заявки. Укажите:

Сторону сделки — «Покупка»
Тип заявки — рыночная или лимитная
Код клиента (номер счёта)
Нажмите «ДА» и ещё раз подтвердите выставление заявки
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 6 из 7
6

Выберите тип заявки

Тип заявки определяет, как будет исполнена сделка:

Рыночная — исполняется сразу по ближайшей рыночной цене в стакане
Лимитная — вы указываете желаемую цену; при наличии встречного ордера заявка исполняется
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
Шаг 7 из 7
7

Сравните инструменты в таблице

Для быстрого поиска выгодной бумаги создайте таблицу текущих торгов: Создать окно → Текущие торги.

Выберите все доступные инструменты в нужном режиме торгов
В доступные параметры добавьте ценовые параметры
В одной таблице удобно видеть информацию по всем инструментам
Источник: внутренняя инструкция АТОН, по состоянию на 09.07.2026
